# Чат-бот консультант на сайте

Круглая кнопка в правом нижнем углу на всех страницах. Клик — открывается окно чата.

## Как это выглядит для покупателя

1. **Знакомство.** Перед первым сообщением — короткая форма: имя, телефон и галочка согласия с политикой конфиденциальности (ссылка на страницу). Без галочки кнопка неактивна.
2. **Диалог.** Помощник знает весь ассортимент студии: названия, категории, описания, цены, размеры, уход. Он расспрашивает про повод, интерьер, бюджет, предлагает подходящие композиции, показывает их карточками с фото и ценой прямо в чате.
3. **Сборка своего варианта.** Можно собрать комплект из нескольких позиций — помощник считает сумму и показывает состав.
4. **Оформление.** Когда покупатель согласен, помощник создаёт заявку (она попадает в раздел «Заказы и заявки» с составом, суммой, именем и телефоном) и одновременно переносит подобранные позиции в корзину на сайте, чтобы покупатель мог довести заказ сам.
5. **Живой оператор.** Если помощник не справляется или покупатель просит человека — чат помечается как «нужен оператор», покупатель видит сообщение «Подключаем специалиста». Ответы оператора приходят в это же окно.

Окно чата сохраняется между страницами и после перезагрузки: покупатель возвращается в свой диалог.

## Что появится в админ-панели

Новый раздел «Чаты» рядом со «Сводкой», «Заказами» и «Товарами»:

- список всех диалогов — имя, телефон, время последнего сообщения, статус (идёт, нужен оператор, закрыт), значок непрочитанного;
- фильтр: все / требуют оператора / новые сообщения;
- открытый диалог: вся переписка покупателя с помощником, поле для ответа от студии — покупатель видит ответ у себя в окне;
- кнопки: «Взять в работу», «Вернуть боту», «Закрыть диалог», «Создать заявку из чата»;
- на «Сводке» добавляется счётчик диалогов, ждущих оператора.

## Техническая часть

- Миграция: таблицы `chat_sessions` (id, `visitor_token`, имя, телефон, согласие, `status` — `bot`/`needs_operator`/`operator`/`closed`, `last_message_at`, `unread_for_admin`, `created_at`) и `chat_messages` (id, `session_id`, `role` — `visitor`/`assistant`/`operator`/`system`, `content`, `payload jsonb` для карточек товаров и расчётов, `created_at`); индексы по `session_id, created_at` и по `status`. GRANT для `authenticated`/`service_role`; RLS: администратор (`has_role`) — полный доступ, `anon` прямого доступа не получает.
- Гость работает через публичные `createServerFn` в `src/lib/chat.functions.ts`: `startChatSession`, `sendChatMessage`, `pollChatMessages`. Личность гостя — случайный `visitor_token` в localStorage; сервер сверяет токен с сессией перед любым чтением или записью и внутри хендлера подгружает `supabaseAdmin`. Валидация имени, телефона и длины сообщения через zod, ограничение частоты по сессии.
- Ответ модели: `openai/gpt-6-astra` через Responses API AI SDK (`createOpenAI(...).responses(...)`, `streamText`, `forceReasoning: true`, `reasoningEffort: "low"`, `store: false`, `include: ["reasoning.encrypted_content"]`), стриминг в роуте `src/routes/api/chat.ts`; `LOVABLE_API_KEY` только на сервере. В системный промпт подставляется актуальный каталог из `products` (опубликованные позиции) на русском.
- Инструменты модели: `suggest_products` (карточки по slug), `quote_composition` (состав и сумма), `create_order` (запись в `leads` с `kind: "order"`, `details` с составом и ссылкой на чат), `request_operator` (перевод сессии в `needs_operator`). Схемы строгие: все поля обязательны, необязательные — nullable, без ограничений длины; `stopWhen: stepCountIs(50)`.
- Корзина: результат `create_order`/`quote_composition` возвращается клиенту, виджет вызывает `addItem` из `useCart` для каждой позиции.
- Доставка ответов оператора: клиент опрашивает `pollChatMessages` раз в 5 секунд, пока окно открыто.
- UI: компоненты AI Elements (`conversation`, `message`, `prompt-input`, `shimmer`, `tool`) устанавливаются из реестра; виджет `src/components/chat/chat-widget.tsx` монтируется в `src/components/site-shell.tsx`. Панель админа — `src/components/admin/chats-panel.tsx` + новая вкладка в `src/routes/admin.tsx`. Цвета только через токены темы, работает в светлой и тёмной теме.

## Проверка

Сквозной прогон в браузере: открыть виджет, заполнить имя, телефон и согласие, попросить подобрать композицию, проверить карточки и расчёт, оформить заявку и увидеть её в «Заказах», проверить перенос в корзину, запросить оператора, ответить из админки и увидеть ответ в окне гостя.
