# Арт-студия Калерия — завершение сайта

Сейчас в превью открывается пустая заглушка: главная страница ещё не собрана, а готовые страницы (каталог, корзина, доставка и другие) выглядят без оформления, потому что общие стили и шапка ещё не подключены. План закрывает это по порядку.

## Что уже готово

- Страницы: каталог с фильтром, карточка товара, корзина с заявкой, мастер-классы, сертификаты, доставка, оферта, политика конфиденциальности.
- База данных: товары и заявки, статусы заявок, права (публичное чтение опубликованных товаров, публичная отправка заявок, полный доступ — только администратор).
- Материалы: ретушированный портрет основательницы и пять фотографий работ (панно, флорариум, моссариум, круг с подсветкой, бонсай).
- Форма заявки, корзина и подсчёт суммы.

## 1. Дизайн-система и шрифты

- Палитра: тёплый айвори как фон, глубокий лесной зелёный как основной акцент, шалфейный как вторичный, древесный и приглушённое золото для деталей.
- Заголовки — Cormorant Garamond, текст и кнопки — Manrope. Шрифты подключаются ссылкой в корневом маршруте.
- Общие стили страниц, которые уже используются в готовых разделах: контейнер страницы, тонкий надзаголовок-линия, крупные поля, тонкие разделители, состояние кнопок и полей.

Результат: все существующие страницы сразу выглядят как один сайт, а не как разные черновики.

## 2. Общая оболочка

- Шапка: название студии, навигация (каталог, мастер-классы, сертификаты, доставка), значок корзины со счётчиком, кнопка «Оставить заявку», мобильное меню.
- Футер: контакты студии, часы работы, ссылки на разделы, конфиденциальность, оферта, вход.
- Корзина работает на всех страницах: добавленный товар сразу виден в шапке.
- Заголовок и описание сайта для поиска, язык страницы — русский, тексты страниц 404 и ошибки — на русском.

## 4. Вход и админка

- /auth — вход по почте и паролю.
- /admin — только для владельца: список заявок (заказы, оценки стоимости, мастер-классы, сертификаты) с фильтрами, статусами «новая / в работе / завершена» и заметками; отдельный раздел товаров с добавлением, редактированием, ценой, фото и публикацией.
- Без входа админка недоступна.

## 5. Товары из базы

- Каталог и карточка товара читают опубликованные товары из базы; если база недоступна, показывается запасной набор из пяти работ.
- Изменения из админки сразу видны на сайте.

## Проверка

- Главная, каталог, карточка товара, корзина — без ошибок в консоли.
- Отправка заявки: сообщение появляется в админке, корзина очищается.
- Калькулятор переносит выбранные параметры в форму заявки.
- Админка без входа не открывается, с входом — меняет статус заявки и товар.
- Десктоп и мобильная вёрстка, сборка проходит без ошибок.

## Техническая часть

- TanStack Start, React 19. Добавляются маршруты `/`, `/auth`, `/admin`; остальные уже созданы.
- Lovable Cloud: таблицы `products`, `leads`, `user_roles`; защита строк (row level security) уже настроена политиками из миграции.
- Чтение товаров — через Supabase-клиент с фильтром `published`, с резервом из `src/lib/store-data.ts`.
- Запись товаров и изменение заявок — только после проверки роли через `has_role(auth.uid(), 'admin')`.
- Сгенерированный модуль проверки входа остаётся без изменений: используемый в нём метод существует в установленной версии библиотеки (проверено), правки не требуются.
- Фотографии работ импортируются из `src/assets`, а новое фото основательницы подключается через CDN-хранилище Lovable Assets вместо `src/assets/kaleria-founder.jpg`.
